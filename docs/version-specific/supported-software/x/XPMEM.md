# XPMEM

XPMEM is a Linux kernel module that enables a process to map the memory of another process into its virtual address space. Source-to-source copy operations between cooperating processes can then be performed at memory speed. This is the userspace library; it requires the xpmem kernel module to be loaded on the host (provided as 'cray-xpmem' on LUMI; verifiable via 'lsmod | grep xpmem' and the existence of /dev/xpmem).

*homepage*: <https://github.com/openucx/xpmem>
