# Flower

Flower: A Friendly Federated AI Framework. Federated learning, federated evaluation, and federated analytics require infrastructure to move machine learning models back and forth, train and evaluate them on local data, and then aggregate the updated models. Flower provides the infrastructure to do exactly that in an easy, scalable, and secure way.

*homepage*: <https://flower.ai>
