# pynco

Python bindings to NCO. This package contains the python module nco, which  implements a python style access to the NetCDF Operators (NCO). NCO is a command line tool for  processing netCDF data. Its main focus is climate data, but it can by used for other purposes  too.

*homepage*: <https://github.com/nco/pynco>
