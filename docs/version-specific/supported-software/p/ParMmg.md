# ParMmg

ParMmg is an open source software for parallel mesh adaptation of 3D volume meshes. The parallel mesh adaptation algorithm is based on iterative remeshing and repartitioning of the distributed mesh. It is inspired by the Yales2 algorithm. ParMmg uses the Mmg software to perform the sequential remeshing steps.

*homepage*: <https://github.com/MmgTools/ParMmg>
