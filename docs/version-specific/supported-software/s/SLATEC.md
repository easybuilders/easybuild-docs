# SLATEC

SLATEC Common Mathematical Library, a comprehensive software library containing     over 1400 general purpose mathematical and statistical routines written in Fortran 77.      netlib.org no longer distributes the complete set of routines (over 700 files that overlap     with BLAS/LINPACK/EISPACK and many special functions were removed from the tarball), so the     sources are taken from a GitHub mirror (Mehdi Chinoune) of the full SLATEC 4.1 library. This     mirror is verified identical to the historical release and adds a CMake build system. The     BLAS/LINPACK routines remain bundled, so libslatec is self-contained.

*homepage*: <https://github.com/MehdiChinoune/SLATEC>
