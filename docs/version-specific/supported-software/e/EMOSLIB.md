# EMOSLIB

The Interpolation library (EMOSLIB) includes Interpolation software and BUFR &  CREX encoding/decoding routines. It is used by the ECMWF meteorological archival and retrieval  system (MARS) and also by the ECMWF workstation Metview.

*homepage*: <https://confluence.ecmwf.int/display/EMOS/Emoslib>
