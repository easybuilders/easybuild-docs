# ggmsa

A visual exploration tool for multiple sequence alignments and associated data. Supports DNA,  RNA and protein sequences using ggplot2, including sequence logos, sequence bundles, RNA secondary structures  and detection of sequence recombinations.

*homepage*: <https://yulab-smu.top/ggmsa/>
