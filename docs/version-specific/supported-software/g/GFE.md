# GFE

The Goddard Fortran Ecosystem (GFE) SDK is a single fixture bundling the  Goddard Fortran Ecosystem libraries used throughout the GEOS-ESM software  stack: gFTL (generic Fortran containers), gFTL-shared (polymorphic/shared  variants of the gFTL containers), fArgParse (command-line argument  parsing), pFUnit (serial and MPI-parallel unit testing framework), yaFyaml  (YAML parser) and pFlogger (Python-logging-style logging library).

*homepage*: <https://github.com/Goddard-Fortran-Ecosystem/GFE>
