# GHOST

GHOST 80 (also known as Ghost or GHOST80) is a Fortran 77 graphics library for making graphs, originally written at UKAEA in the 1980s. It provides plotting routines and several output device drivers (X11, HP-GL/2, PostScript, ...).

*homepage*: <https://github.com/ZedThree/GHOST>
