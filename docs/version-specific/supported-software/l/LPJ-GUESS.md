# LPJ-GUESS

LPJ-GUESS is a process-based dynamic vegetation-terrestrial ecosystem model designed for regional or global studies. Models of this kind are commonly known as dynamic global vegetation models (DGVMs).

*homepage*: <https://web.nateko.lu.se/lpj-guess/>
