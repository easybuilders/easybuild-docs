# Bandicoot

Bandicoot is a high quality GPU linear algebra library (matrix maths) for the C++ language, aiming towards a good balance between speed and ease of use. Provides efficient classes for dense vectors and matrices that hold integer and floating-point numbers.

*homepage*: <https://coot.sourceforge.io/>
